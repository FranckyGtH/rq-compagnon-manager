# RQ compagnon Manager 0.17.3

Première version préparée pour GitHub. Nouveau nom dans les applications et macros, icônes Glorantha et compatibilité avec les dossiers existants.

Le module fournit les applications DM et PC, la gestion XP/TP/DP, Season Training, les caractéristiques, le downtime et son Training ciblé, les sauvegardes privées et la resynchronisation.

Configuration ciblée : Foundry VTT 14.367 / RuneQuest Glorantha 6.1.1. Les mécanismes de progression proviennent de la version stable 0.17.1 testée dans Foundry par l'utilisateur. Le paquet et la mise à jour des macros sont vérifiés dans les tests automatisés ; l'installation du module et l'accès aux macros ont été confirmés sur The Forge. L'installation via le nouveau lien GitHub reste à vérifier après publication.

Les données privées du compendium restent dans le monde. Les cinq dernières références complètes sont conservées. Le module ne contient aucune fiche de personnage ni sauvegarde de campagne.
